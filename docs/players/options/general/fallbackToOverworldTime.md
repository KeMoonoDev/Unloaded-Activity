!!! note "Default value: **true**"

!!! note warning "This option is only for Minecraft 26.1 and above."
    Versions below 26.1 will have the same behavior as if this value was set to true.

This option makes it so dimensions with no clock assigned to them will use the
overworld time. In vanilla Minecraft, these dimensions are The Nether and The
End.

If this is set to false, those dimensions will not be simulated, unless you use
[`useSystemTime`](../useSystemTime).
